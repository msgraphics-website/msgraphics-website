=== M.S. Graphics Studio Shop (Astra child theme) ===

Makes the WooCommerce shop look like the main M.S. Graphics Studio website:
same header, footer, colours and font, plus a new shop banner, category bar,
product cards, product page help box, cart, checkout and account pages.

Needs: the Astra theme installed (do not delete it) and WooCommerce.
Settings: Appearance > Customize > M.S. Graphics Studio.
To undo: Appearance > Themes > activate Astra again.
